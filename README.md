# HPYNO

Immersive 3D hypnosis experiences for the browser. Watch mode: an audio-reactive velvet tunnel with a living focal point, word-synced narration, and hold-to-consent gates. Listen mode: lock the phone, close your eyes, tap when she asks.

```bash
npm install
npm run dev       # http://localhost:5173/hpynoai/
npm run check     # types + lint + tests
```

See `CLAUDE.md` for architecture and rules.
